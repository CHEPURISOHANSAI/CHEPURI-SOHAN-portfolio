## 🚀 Getting Started

### Prerequisites
- Node.js (v20+ recommended)
- pnpm or npm

### Installation
```bash
# Clone the repository
git clone https://github.com/CHEPURISOHANSAI/CHEPURI-SOHAN-portfolio.git

# Navigate into the project
cd CHEPURI-SOHAN-portfolio

# Install dependencies
pnpm install
```

### Development
```bash
pnpm dev
# Server will start on http://localhost:8443
```

### Production Build
```bash
pnpm build
pnpm preview
```
